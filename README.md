# Drama space MAX

Max/MSP tools and impulse-response assets for transforming a club impulse response into a drama-space / hall response.

## Included

- `patchers/`: Max patchers for downmixing, compensation filtering, and the HWACON system
- `code/`: Max JavaScript helpers
- `other/` and `final backup/`: Python FIR and IR conversion scripts
- `data/`: Max snapshots and convolution settings
- `250930 hwacon2/`: selected six-channel IR and compensation-filter assets
- `media/` and `final backup/`: representative rendered results and reference images

## Notes

This repository is a curated, GitHub-sized subset of the original `Archive.zip`. The original backup is approximately 6.5 GB and contains duplicated media, intermediate renders, macOS metadata, and a large external IR library, so those items are intentionally not committed here.

The scripts may require Python packages and Max/MSP dependencies that are not bundled in this repository. Paths in the Max patchers may need to be updated for your local machine.
